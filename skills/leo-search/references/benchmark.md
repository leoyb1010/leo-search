# Search benchmark

Maintain a versioned benchmark plus a small live set. Frozen questions make releases comparable; live questions prove freshness.

Recommended coverage:

- current news, products, people and companies;
- exact library/framework versions;
- GitHub repositories, releases, issues and code;
- papers and date-bounded research;
- RSS, video and subtitles;
- Chinese and account-bound platforms;
- questions that should return an explicit boundary or uncertainty.

Measure claim-support precision, key-evidence recall, citation reachability, event/publication freshness, version match, independent-source recognition, route status accuracy and latency. Do not optimize precision by withholding useful Discovery leads; score labeled hypotheses separately from asserted facts.

Before promoting a new provider, run a focused capability spike. It must materially improve at least one measured dimension over existing routes without unacceptable regression elsewhere.
